# Theme contract

Everything visual that is shared between screens. Source of truth: `crates/ui/src/theme.rs` (tokens, fonts, `apply`) and `crates/ui/src/kit.rs` (widgets and layout). Dark theme only (see CONVENTIONS.md): no light theme, no `dark_mode` parameters.

## Colours (`ui::theme`)

| Token | Hex | Use |
|---|---|---|
| `WINDOW_BG` | #1C2024 | The base colour: toolbar, panels, dialogs, overview/spectrogram rulers, measure header, staff and tab strips, TRACKS corner |
| `TITLE_BG` | #16191D | Area behind the track lanes (one shade darker) |
| `PANEL_BG` | #262B31 | Tool-group panels, track headers, inactive widgets |
| `INPUT_BG` | #171A1E | Text fields, dropdown fields (`extreme_bg_color`) |
| `BORDER` / `BORDER_STRONG` | #333A43 / #444C58 | Strokes / hovered strokes |
| `TEXT` / `LABEL` / `HINT` | #E8EAEE / #D5DAE3 / #9AA3B2 | Primary text, field labels, captions and secondary text |
| `ERROR` | #E55B5B | Invalid input |
| `LOGO_GLOW` | #283847 | Home screen glow only |

- New surfaces use `WINDOW_BG`; do not introduce new greys. Use `PANEL_BG` only for raised groups and headers.
- The toolbar has no outer border; only a 1 px bottom line separates it from the overview.
- Radii: `CONTROL_RADIUS` 8 (buttons, fields), `PANEL_RADIUS` 14 (groups, windows), `kit::SMALL_R` 6 (small pills).

## Accent

Runtime-configurable: `set_accent(c)` then `apply(ctx)`. Read it with `accent()`; never hard-code `DEFAULT_ACCENT` (#F0AA3C). Derived helpers: `accent_text_on()` (readable text on the accent), `accent_hover()`, `focus_ring()`. The accent marks "on"/active state, the filled part of sliders, selection and focus.

## Fonts

- Only Inter (`FontFamily::Proportional`), Inter Medium (`theme::medium()`: buttons, headings, captions) and JetBrains Mono (`FontFamily::Monospace` and `theme::mono()`).
- egui's Hack, Ubuntu and Noto fonts are removed (`add_fonts`). Fallbacks: egui's `emoji-icon-font` (arrows of egui menus, the quarter-note sign `♩` of the tempo label) and Bravura (SMuFL), which is only for staff notation glyphs.
- Install with `theme::install_fonts(ctx)` (theme + notation fonts in one `set_fonts`). Default text styles: Body 14, Button 14 (medium), Heading 22 (medium), Small 12, Monospace 12.5 (`apply`).
- Test contexts have no custom fonts: `theme::medium()` panics there. Code exercised by tests uses `FontId::proportional`, or the test calls `install_fonts`.
- Do not draw Bravura glyphs inline in text labels (it inflates the line height).

## Icons

- Bundled SVGs in `crates/ui/assets/icons/`, drawn on a 24 px grid, stroke 1.75, colours #E8EAEE (primary) and #9AA3B2 (secondary). Generated by `icons/gen_icons.py` (project docs); edit the generator, not the SVGs.
- Use through `kit::icon(name)` / `kit::icon_at`; `kit::install(ctx)` registers the SVG loaders at startup. Icon names are file names without extension.
- Icon-only buttons always carry a tooltip.

## Layout rules (`ui::kit`)

- Buttons are `kit::BUTTON` = 36 px (28 px in the tab tool row); `ibtn` / `ibtn_sized` / `play_button`, `button_bg` for the shared fill/hover/on/focus look.
- Groups (`group`, `group_at(above)`, `group_frame`, `group_frame_h`): `PANEL_BG`, `PANEL_RADIUS`, inner padding and item gap both 4 px (so spacing inside matches spacing to the edge), caption (`caption_at`) in `HINT` small medium text above or below. Rows are separated by `ROW_GAP` 8 px, including the gap to the bottom separator. `TOOLBAR_HEIGHT` (tab toolbar) is 54.
- Right-side groups use `kit::right_aligned`; separators are 1 px (`sep`).
- Fixed-width values: dropdowns and numeric fields have a fixed width sized for their widest entry plus padding (never content-sized, never clipped). Steppers grey out `-` / `+` at their limits.
- `Field` / `dropdown` / `menu_rows` / `Dd`: the same presentation as the New project form (pill field, chevron, popup rows wide enough for one line per item). `text_field` + `FieldOpts { width, height, invalid, left, right, commit, tip }` for typed fields (tuning, reference pitch, capo).
- Mouse wheel over a dropdown, stepper or slider changes its value (`kit::wheel`, `wheel_value`); the wheel is consumed so the view behind does not scroll. Right click on a division dropdown toggles `None` / previous value.
- Sliders: `style_slider` (accent-filled trail); slider popups via `slider_popup`.
- Labels are not selectable (`selectable_labels = false`).
- Dialog windows use `theme::dialog_frame(ctx)` (`WINDOW_BG`), never the default window fill.
- Layout pitfalls: do not read widget focus inside `ui.data_mut` (nested context lock freezes the app); nested `vertical` fills the remaining width, so size groups explicitly.

## Where things live

- Editor chrome: `crates/app/src/toolbar.rs`, `editor.rs` (overview gutter = `LANE_HEADER_WIDTH` 240, TRACKS corner, collapsible notation panel).
- Track headers and Add track button: `crates/ui/src/tracks/header.rs`; backdrop in `lanes.rs`.
- Shared form widgets: `kit` (used by `crates/app/src/form_ui.rs`).
