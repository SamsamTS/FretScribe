# Contract changes

Only what other crates or the app rely on. Newest entries last.

## 2026-11-01 - audio

- Workspace deps: `signalsmith-stretch` (needs a C++ toolchain and libclang; used only via `audio/src/stretch.rs`); `rodio` with `default-features = false` (symphonia decodes); `serde_json` with `float_roundtrip` (saved projects must reload equal); `[profile.dev.package."*"] opt-level = 3`.
- API (project time): `decode_file`, `decode_files` (parallel, input order), `DecodedAudio`, `AudioError`; `PreparedAudio::new(&DecodedAudio, Player::output_rate())`, `PreparedTrack`, `Player::set_prepared_tracks` (`AudioError::RateMismatch` on a wrong rate); `Player`: `set_tracks`, `load`, `play`, `pause`, `stop`, `seek`, `is_playing`, `position_sec`, `duration_sec`, `set_volume`, `set_region`, `set_loop`, `set_playback_speed`, `set_speed_mode`, `set_track_{volume,mute,solo,offset}`, `track_peak_levels`, `set_note_overlay`, `set_reference_pitch`.
- Track audibility follows `core::audible_tracks`; volume is clamped like `Track::set_volume`.
- Guitar focus filter (listening aid only, never applied to analysis or spectrograms; default off): `Player::set_guitar_focus`, `set_guitar_focus_strength` (0..1), `set_focus_context(&Tuning, capo)` (call on open and on every tuning/capo change, undo included); `focus_band`; `apply_focus_offline`. Acts on the track sum, before the note overlay.

## 2026-11-02 - analysis: spectrogram

- Workspace deps: `rayon`, `image` (png only); `[profile.dev.package.fretscribe-analysis] opt-level = 3`.
- `compute_spectrogram`, `compute_spectrogram_streaming` (chunks in time order, `Spectrogram::empty(&info)` + `apply_chunk`; dropping the receiver cancels).
- `Spectrogram { data 0..1, n_frames, n_rows, hop_sec, min_midi, max_midi, bins_per_semitone }`: row 0 = lowest pitch, frame `i` centred at `i * hop_sec`. The row grid is always relative to A4 = 440 Hz; `row_to_midi` / `midi_to_row` take the `PitchRef`.
- `render_rgba` (image row 0 = highest pitch), `Levels`, `apply_levels`, `apply_gamma`, `APP_GAMMA`/`APP_WHITE`, `suggested_levels()`, `Lut`/`discover_luts`, `AnalysisError`.
- Palettes are PNGs in the root `LUT/` folder (must ship next to the executable; `Lut::builtin()` is the fallback), regenerated by `cargo run -p fretscribe-analysis --example make_luts`.
- `export_spectrogram_png` is a `harness = false` test target and ignores `--nocapture`/`--quiet`/`-q`.

## 2026-11-03 - analysis: waveform

- `export_waveform_png` is a `harness = false` test target.

## 2026-11-05 - ui: overview and navigation

- Overview snapping: on by default, Alt disables it (or enables it when the magnet button is off). `OverviewTimeline::snapping(bool)`, `OverviewEvent::SnapToggled(bool)` (the app stores the state); `DragContext::snap: &[f64]`.
- `nav` (`ViewController`, `ViewTuning`, `NavContext`, `NavRegions`, `nav::ViewState { scroll_sec, scroll_y, pixels_per_sec }`): `ctl.run(ctx, &NavContext)` once per frame; widgets read `current`. The app must set `ctx.options_mut(|o| o.zoom_with_keyboard = false)`. `scroll_y` is not persisted. Feel constants live in `nav/tuning.rs`.
- Alt + wheel is read by the lane (resizes it), not by the nav; the pitch range is always shown in full (`ViewController::pitch` stays, pitch zoom removed).

## 2026-11-06 - analysis: beat fit, track sync, reference pitch

No change in other crates. Modules are not re-exported at the crate root.
- `beatfit`: `onset_envelope`, `detect_onsets`, `combine_envelopes`, `envelope_input` (`None` unless `use_for_beats`), `default_weight`, `fit_measures`, `fitted_grid` (feeds `Project::auto_fit`, callers pass `KeepAudioPosition`), `estimate_tempo`, `octave_ratio`.
- `sync`: `assume_synced`, `estimate_offset(reference, other, rate, SyncOptions) -> Vec<SyncCandidate>` (max 3, best first; both signals at one sample rate, the caller resamples; `project_time = audio_time + offset_sec`), `snap_offsets`. Full-signal FFT correlation: about 300 MB for two 3-minute tracks.
- `pitchref`: `estimate_reference(mono, rate, region, PitchRefOptions) -> PitchRefEstimate { cents, a4_hz, confidence, histogram }`. Estimates only; `cents` is the offset from the 440 grid in -50..=+50 (a semitone shift or capo reads about 0).

## 2026-11-07 - ui: spectrogram view

- `fretscribe-ui` depends on `fretscribe-analysis` and `fretscribe-notation`.
- `notation::tab::{lowest_fret_candidate, candidate_label}` are provisional ("E 10" format, string 0 = lowest, capo respected); replace with the real tab inference keeping the signatures.
- `spectro`: `SpectrogramView::show(ui, &TimelineView, &PitchView, &mut SpectroCache) -> SpectroOutput`, `SpectroStyle`, `SpectroEvent::{AddNoteRequested, SeekRequested}`, `GhostNote`, `HitZone`, `hit_test`, `SpectroGeometry`, `WaveformView`, `show_time_ruler`; `view::PitchView { min_midi, max_midi }`.
- Notes are `&[Note]` plus `NoteTimes`; the connector kind is the start note's `technique` (Slide, Bend; otherwise a plain line).
- Texture cache key includes window, size, pitch range, A4, levels, gamma, LUT, data pointer and a caller `revision` (bump it when data changes in place).
- `SpectroOutput::pitch_ruler` (`PITCH_RULER_WIDTH`) is the left label strip: used for the nav drag, clicks there add no note.

## 2026-11-07 - ui: track lanes

- `tracks`: `TrackLanes`, `TrackLane`, `TrackHeader`, `TrackLanesState`, `LaneOptions` (display preferences owned by the app), `LaneSource`, `TrackEvent`; `view::LANE_HEADER_WIDTH` (240 pt).
- Geometry in whole physical pixels: `STRIP_PITCH_PX = 67` (pass as `NavContext::strip_pitch_px`), spectrogram 1..=16 rows (default 5), drag the lane's bottom edge or Alt + wheel to resize (wheel resizes glide). `TrackLanesState::strips` / `content_px` feed the nav before `show`.
- Timeline x = 0 is the right edge of the header column: ruler and grid start `LANE_HEADER_WIDTH` right of the lane area. `TimelineView` stays in project time; only a lane's spectrogram and waveform are shifted (`audio_offset`), notes never are.
- `LaneSource` supplies spectrogram, peaks, duration, onsets and `snap_candidates` in the track's own audio time.
- Offsets: `OffsetDragBegan(id)` / `OffsetDragEnded(id)` bracket the live `OffsetChanged` events of one drag (one undo step); typed, nudged and reset values send one event each. `OffsetChanged::move_notes` is true only for the source track with the menu option on; the app applies it with `core::shift_track`. Limit +-60 s; snap within 8 px, Alt disables, Shift drags 10x slower; the field commits on Enter, Esc reverts.
- Clicks on a helper lane's spectrogram give `SpectroEvent::SeekRequested`, never `AddNoteRequested`.
- `LaneOutput::resized_rows` is `Option<(rows, animate)>`; `geometry::rows_shown` takes `rows: f32`.
