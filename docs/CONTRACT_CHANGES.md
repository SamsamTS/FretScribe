## 2026-11-09 - legato, grace notes, tied links

- `core::grace`: `Project::{link_legato(from, to, Option<Legato>), force_legato, unlink_legato, add_grace_note(main, Option<midi>, GraceKind), set_grace_kind, set_grace_timing(id, kind, len_sec), remove_grace, force_legato_selection, previous_note, try_edit, grace_target, grace_link, set_grace_link, default_grace_link}`, `grace_target_of(notes, times, id)`; `GraceError`, `LegatoError` (`NeedsSameString { candidates }`), `LinkError::NoPrevious`, `ACCIACCATURA_SEC` (40 ms), `APPOGGIATURA_SEC` (100 ms), `default_grace_midi`. Grace notes use the same one-link rule as every link. `infer_link_type` (hence `link_selection`) gives a slide when both notes have different string assignments; `ForceLegato` instead moves and locks the destination.
- Grace placement is the kind: `Acciaccatura` = before the beat (ends at the start of the note it leads into), `Appoggiatura` = on the beat (starts at the main note's start, drawn over it). `set_grace_timing` limits the length by the room (back to the previous note's start, or the main note's length) and re-checks the link; `set_grace_kind` switches side keeping the length.
- A grace note always joins the note that follows it (the next grace note of the group, else the main note). Several on-the-beat grace notes all lead into the main note, so only the first can keep a legato or slide.
- `LinkType::CYCLE = [Slide, Bend, Legato, Dashed]`; `Project::{link_of(id), valid_links(id), set_link_type(id, kind) -> bool}`; `cycle_link_type` serves grace notes too. `Dashed` is valid for grace sources only (`LinkError::DashedNeedsGrace`) and implicit (no stored data, `grace_of` alone; `link_of` returns the real link, else the dashed one); renderers draw it from `grace_target_of`.
- Tie rule: when A links to B, `A.end == B.start`. `link_notes` sets `A.end` to `B.start` (`LinkError::NotInOrder` when A would be left under `MIN_TIED_SEC`). `Project::tie_links(touched) -> Vec<u64>` re-ties after any edit (a link that would leave under `MIN_PIECE_BEATS` is dropped) and runs first in `resolve_overlaps`. Exception: an on-the-beat grace note (`ties_end` false) keeps its own length.
- Note editor: `NoteAction::{Grace, ForceLegato, NudgeBeat(i8), SnapPreset { next }}`, `Applied::{grace_entry, snap_grid}`, `Effect::SnapGrid(SnapGrid)` (the app stores the grid), `Input::Cut`. Grace on a grace note starts an entry on its main; H/P toggles legato (removes it when all targets already have it); Type works on grace notes. Right click on a grace note, its connector or arc cycles its valid links (one undo step, merged while cycling).
- Grace entry: modal (`GraceEntry`, `Input::Entry(EntryKey)`, `NoteEditor::in_entry`/`in_mode`; the app's key collection must route keys to it while true, `collect` does); `Effect::Edit` of the entry affects `[grace, main]`. The pointer draws the note from the main note's start (left = before the beat, right = on the beat, distance = length; within 10 ms: the kind's default length), `GraceEntry::pointer(project, sec, midi)`; a left click or Enter confirms, `EntryKey::CycleLink` cycles the link, G switches side keeping the length.
- Link bands: a link source is drawn as a band (about `h` wide plus dot room, at most half the way to its destination, right edge locked). `Scene::locked` gives the locked edges (also a before-the-beat grace note's end and an on-the-beat one's start, which `plan_resize` refuses); `Scene::name_area(id)`. Resizing a link end drags the tied edge. Resizing a note's start moves its grace notes with it; grace notes whose main is not moved are left out of multi-moves; a lone grace note has two positions (on or before the beat).
- Drawing onto an existing note links the new note to it (`draw::plan_draw_onto`; the press is one end and the target the other); while a drawn slide waits for its end, a left click on an existing note does the same (`plan_slide_target`). A drawn slide is A[s,e], B[e,e+step].
- On-the-beat grace links are drawn from the grace note's right edge towards the main note.

## 2026-11-10 - note editor keymap, notation: tab inference

- `ui::note_editor::Keymap` (`KeyChord`, `KeymapError`): defaults in one table, overridable from a JSON file `{ "<action id>": "Chord" | ["Chord", ..] }` (`[]` unbinds, unlisted ids keep their defaults; unknown ids, bad chords and conflicts are errors). `Keymap::load_or_default(path) -> (Keymap, Option<String>)` (the message goes to the status bar), `to_json` / `save(path)`; the app picks the path (e.g. `%APPDATA%\fretscribe\keymap.json`), loads it once and passes it to `collect(ctx, src, events, editor, keymap, refine)` and `action_buttons(project, selection, keymap)` (tooltips come from it). Fixed keys: Esc, Ctrl+C/X/V (egui events), Ctrl+Z/Y (app).
- Keys `1`-`9` are `NoteAction::SetStringFromTop(n)` (string 1 = highest of the tuning), `0` unlocks; past the tuning's size gives `ActionError::NoPlacement`.
- `notation::tab`: `TabOptions` (adds `grace_bonus`), `candidates`, `presets`, `LabelStyle`, `string_label[_styled]`, `candidate_label[_styled]` (return `Option<String>`, `None` for a missing string; the top string is lowercase, so standard tuning reads `E A D G B e`), `assign_tabs`, `assign_tabs_range`, `lowest_fret_candidate`, `group_options`/`GroupOption` (strings that play a note's whole slide/bend/legato group, with the frets that follow; locks ignored).
- Both assign functions take `&NoteTimes`: `assign_tabs(notes, times, tuning, capo, opts) -> Vec<u64>` (unplaceable ids), `assign_tabs_range(notes, times, tuning, capo, opts, edited_index, propagate_backwards) -> Vec<u64>` (changed ids). `edited_index` indexes the slice; notes need not be sorted.
- The app calls `assign_tabs_range` after a lock/unlock (`Effect::Edit { affected }`) and `assign_tabs` on open and on tuning/capo changes. Locked notes are never rewritten. Notes linked by slide, bend or legato are one same-string group. Open strings count at 0.75 of the fret distance for movement (spec: ignored).

## 2026-11-11 - notation: staff layout, ui: staff view and tab view

- `notation::staff`: `layout(&[Note], &[Measure], &StaffOptions { grid: SnapGrid (default [4,3]), key: KeySignature, guitar_octave (default true) }) -> StaffLayout { key, guitar_octave, measures, events: Vec<StaffEvent>, beams, tuplets, links }` plus `note_ref(id) -> NoteRef { first, last, grace, index }`; `spell(midi, KeySignature)`; `bend_label` is public. Pure; call it again after any edit. (Differs from the spec's `StaffEvent`/`GlyphItem` sketch.)
- `StaffEvent`: one engraved value (note/chord piece or rest): `measure`, `beat_pos`, `duration_beats`, `duration { base, dots, triplet }`, `rest`, `whole_measure`, `notes: Vec<StaffNote { id, midi, step, accidental, tie_next, displaced }>` (lowest first), `graces: Vec<GraceMark>`, `x_sec`/`x_end_sec` (real start of the note, snapped time for rests and tied pieces), `stem_up`, `beam`. `step` is the staff step of the WRITTEN pitch (0 = bottom line, E4; guitar transposition applied).
- Rhythm: 24 ticks per quarter; every quarter-note window picks the grid division that fits best (straight wins ties). Rests are derived and stop after the last measure holding notes; a rest never crosses a main beat (6/8 beat = dotted quarter); a note may cross beats only from a beat and not over the middle of the measure unless it starts it. Gaps under half the finest grid step are absorbed. Grace notes take no time and take no part in the rhythm. Accidentals: once per measure and staff position, naturals when needed, not repeated on a tied continuation.
- `ui::staff_view`: `StaffView { layout, selected, playhead, style, timeline_offset }.show(ui, &TimelineView) -> StaffOutput { events, hovered, response }`; `StaffViewEvent::{NoteClicked { id, ctrl, shift }, NoteContext(id), SeekRequested(sec)}` (the app maps click to `Selection::click`, right click to the H/G handling of the note editor). `StaffStyle` (space 7 pt, light ink on dark).
- `timeline_offset` is the width of the left column (clef and key signature) in both staff and tab views; `x = widget left + offset + TimelineView::sec_to_x`, so notes and barlines align with the spectrogram. A time signature is drawn just left of its barline.
- Fonts: call `staff_view::install_fonts(&ctx)` once (or `add_fonts(&mut FontDefinitions)`). Bravura 1.392 is bundled as `crates/ui/assets/Bravura.otf` with `Bravura-OFL.txt`.
- Staff drawing: slides are a line between noteheads, bends a curved arrow labelled "1/2" / "full" / "1 1/2" (downward for a release), legato an H/P slur; grace notes are small noteheads (slashed before the beat). Dashed grace connectors are not drawn.
- `ui::tab_view`: `TabView { project, times, staff (stems only), selected, playhead, style, opts, timeline_offset }.show(ui, &TimelineView, &mut TabViewState) -> TabOutput { events, hovered, response }`; the app owns `TabViewState` (`propagate_backwards`, `show_stems`, `string_colors`, `high_contrast`, `tuning` popup, `flash(ids, now)`). Fret numbers are the neck fret (capo included); unassigned notes show a red "?".
- `TabViewEvent::{NoteClicked, SeekRequested, Edit(TabEdit), TuningChanged { tuning, capo }, Marquee { ids, add }, ClearSelection}`, `TabEdit::{SetString, MoveString, Cycle, Lock, Reset, Legato, SetLink}`. Selection matches the note editor: click -> `Selection::click` (Ctrl toggles, Shift adds the time-ordered range via `time_order`, Alt cycles), right-drag marquee -> `Selection::marquee`, right click on empty -> `clear`; right click on a note selects it and opens the menu (`menu_model`: placements via `candidate_label`, "(auto)", string colours from `string_color(index, count)`; group menu inside a multi-selection).
- The app calls `tab_view::apply(&mut project, &edit, &opts, state.propagate_backwards) -> TabApplied { edit, changed }` (manual change, lock and `assign_tabs_range` update are ONE `ProjectEdit`; flash `changed`) and `apply_tuning(&mut project, tuning, capo, &opts) -> ProjectEdit`.
- Holding the left button (>= `HOLD_SEC` 0.15 s) or an open menu shows string colours. Keys (Up/Down adjacent string, Tab / Shift+Tab next / previous placement) act only while the pointer is over the view and are consumed: call `TabView::show` before the note editor collects keys.
- Demos: `cargo run -p fretscribe-ui --example staff_demo` (`-- --screenshot out.png` saves a frame and quits), `--example tab_demo`.

## 2026-11-12 - core: delta undo, history thinning and persistence

- `ProjectEdit` stores a delta (changed notes by id, other groups whole), not two snapshots. `Project::notes` is sorted by id (new ids are max + 1; `from_json` sorts). Undoable: tracks (except the live fields), `source_track`, measures + `next_measure_id`, tuning, capo, `reference_hz`, notes.
- Live track fields `volume`, `muted`, `solo`, `spectrogram_collapsed` are never restored by undo/redo (a track re-added by undo takes the delta's values): the app must re-send track state to the player after every undo/redo.
- `Project::set_reference(hz) -> Result<ProjectEdit, CoreError>` (validated); `UndoError::Diverged`; `ProjectEdit::{try_undo, try_redo, weight}` (`undo`/`redo` apply nothing on divergence). `UndoStack::undo/redo` clear the history on divergence and return `None`; `take_diverged()` is true once so the app can toast.
- `UndoPolicy { min_entries: 20, per_level: 3, max_entries: 200 }` (serde; keep it in the app settings): `UndoStack::{with_policy, set_policy}` (applies at the next push), `with_limit(n)` sets `max_entries` (`min_entries` is lowered below it when needed). Old history is thinned on a log scale; `undo_weight()` / `redo_weight()` give the steps an entry covers.
- `UndoStack::{to_saved, from_saved(saved, &project, policy)}`, `SavedHistory`, `ProjectFile::history` (optional, no version bump; the app sets it before saving only if the history is kept with the project, and takes it after loading; autosave carries it too). `from_saved` never fails: it keeps the newest run that replays and validates; an unreadable `history` is dropped by `from_json`.
